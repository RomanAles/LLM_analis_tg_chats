# Проверка версии 1.0.0

Дата: 31.10.2026. Все использованные переписки синтетические.

## Окружение

- Windows, отдельный `.venv`, созданный Python установленной Miniconda.
- Python 3.13.5, SQLite 3.50.2; runtime приложения использует стандартную библиотеку.
- Сборка: setuptools 80.9.0, wheel 0.45.1.
- NVIDIA RTX 4070 SUPER 12282 MiB; фактическое выполнение LLM на GPU не проверено.

## Проверено

- Все 33 автоматических теста проходят; wheel собран, статические файлы и демо
  включены в пакет; pip check не обнаружил конфликтов.
- Исправления исходного извлекателя покупок, включая ошибки JSON и ID источников.
- Импорт, обновления, часовой пояс, изоляция чатов и сохранение исходников.
- Связи ответов, темы форума, циклы и отсутствующие родители, разбиение длинного текста.
- Словарный поиск, исключения, наследование контекста и контракт embeddings-адаптера.
- Отбрасывание выдуманных ID и цитат, различение ошибок и отсутствия результата.
- Продолжение после остановки, кэш, повтор ошибок и обновление корпуса/темы.
- HTTP: синтетический пример → анализ → четыре формата выгрузки → оценка находки.
- Браузер: загрузка демо, запуск, 15 находок, 100% охват обработки,
  повторное использование пяти фрагментов из кэша, открытие контекста сообщения.
- Вредные инструкции в синтетической переписке показаны как данные; файлов не создают.

Эти короткие искусственные сценарии и явные словари темы проверяют регрессии.
Они не измеряют способность обобщать на произвольные реальные переписки.
После просмотра метрик holdout считается регрессионным набором.

## Ограничения проверки

- Веса Qwen/Mistral не скачивались и runtime Ollama не устанавливался.
- Превосходство Qwen3.5-9B над исходной Mistral пока не измерено.
- Реальные embeddings, скорость LLM, память и качество смысловой интерпретации
  требуют отдельного прогона на установленных моделях. Текущий выбор предварительный.
- Адаптер Transformers предназначен для текстовых Causal LM. Для Qwen3.5 используйте Ollama.
- Отчёт группирует структурированные находки; автоматическая проверка противоречий
  и отдельное длинное повествовательное резюме пока не реализованы.
- Корпус загружается в память; для очень больших экспортов понадобится потоковый импорт.
- Веб-загрузка ограничена 24 MB исходных файлов; крупнее — через CLI.

## Продолжение

Пользователь попросил закончить текущий шаг и остановиться. Разработка остановлена
после реализации интерфейса и фиксации результатов. Следующая самостоятельная
работа — установка выбранного runtime/весов и сравнительная оценка LLM.
