# Проверка качества

Данные целиком вымышлены. Генератор `scripts/generate_synthetic.py` не читает
реальные файлы переписок, не вызывает LLM и не использует случайные сетевые данные.
Повторный запуск воспроизводит те же экспорты и независимые метки `labels.json`.

- dev: домашние NAS; используется при разработке.
- holdout: электровелосипеды; отличается темой и формулировками. Не используется
  для подбора словаря/промпта по результатам; после просмотра метрик становится
  регрессионным набором. Для независимой следующей оценки нужен новый holdout.

Сценарии: короткие ответы, несколько разговоров одновременно, отрицания,
намерения и объявления вместо покупок, чужие цитаты, форматированный текст,
отсутствующий автор, служебные записи, вложения без текста, инструкции внутри чата.

Метрики:

- precision / recall / F1 релевантности на уровне `(chat_id, message_id)`;
- доля успешных разборов ответа и технических ошибок;
- доля находок с существующими ID и дословными цитатами;
- дубли событий, отдельно от нескольких сообщений об одном событии;
- длительность, число фрагментов, повторно использованный кэш;
- ручная оценка смыслового соответствия вывода цитате.

Числа на 44 записях — проверка регрессий, а не оценка качества на настоящих чатах.
Наличие точной цитаты не доказывает правильность интерпретации или типизации.
При сравнении моделей: одинаковые корпус, тема, контекст, промпт, квантование,
бюджет ответа; модель и runtime фиксируются в отчёте запуска. Сначала dev,
потом однократная контрольная оценка. Самооценка уверенности LLM не используется
как измеренная вероятность.
