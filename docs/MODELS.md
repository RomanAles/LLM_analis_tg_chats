# Локальные модели: выбор 31.10.2026

Проверенное оборудование: NVIDIA GeForce RTX 4070 SUPER, 12282 MiB VRAM.
При проверке было свободно 10169 MiB. Объём системной RAM не установлен.

## Кандидаты

| Модель | Роль | Лицензия | Почему рассматривается |
|---|---|---|---|
| Qwen3.5-9B, 4-bit через Ollama | Основной кандидат | Apache 2.0 | Современная многоязычная модель; разумный размер для 12 GB |
| Qwen3.5-4B, 4-bit через Ollama | Быстрый вариант | Apache 2.0 | Меньше памяти и время обработки; качество нужно измерить |
| Qwen3-8B, 4-bit | Запасной текстовый вариант | Apache 2.0 | Совместим с AutoModelForCausalLM; отключаемое thinking |
| Mistral-7B-Instruct-v0.3 | Исходная точка сравнения | См. исходную карточку | Существующий прототип; не объявляется победителем или проигравшим без теста |

Сначала контекст 8192, короткие обсуждения и `think=false`. Большой заявленный
контекст модели не означает, что он поместится в 12 GB. Размер весов не равен
потреблению памяти: нужны runtime, рабочие буферы, KV/state cache и запас для ОС.
Qwen3.5 является мультимодальной архитектурой; существующий Mistral-адаптер
AutoModelForCausalLM не следует автоматически считать совместимым с ней.
Для Qwen3.5 основной путь здесь — Ollama API с JSON Schema.

Бесплатность означает отсутствие оплаты API при локальном запуске. Модель
не отправляет переписку во внешний API; разрешены только loopback-адреса runtime.

## Запуск после установки Ollama

```powershell
ollama pull qwen3.5:9b
# Более лёгкая альтернатива:
ollama pull qwen3.5:4b
```

Скачивание весов выполняется явно. Проект при анализе их не загружает.
Размеры и квантование тега могут изменяться; перед сравнением сохраните digest
и сведения runtime. Фактическое преимущество на русских чатах не измерено:
нужен одинаковый синтетический набор, валидность JSON, precision/recall,
соответствие цитат и время. Рекомендация предварительная, по размеру и функциям.
