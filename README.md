# Поиск завершённых покупок в чатах Telegram

Аналитика диалогов с помощью локальной LLM — Mistral-7B-Instruct-v0.3

## О проекте

`pre_relis.py` — скрипт, который автоматически анализирует переписку и извлекает факты покупок:

* кто совершил покупку
* что купил
* за какую цену

Может применяться в чатах с продажами, групповых закупках, тематических сообществах и т. д.

Работает локально на пользовательской машине.

## Используемая модель

Модель: `Mistral-7B-Instruct-v0.3`
Загружается из локального каталога, квантована в 4-бита для экономии VRAM.

По желанию можно заменить на любую другую Causal LM, изменив путь к модели.

## Формат входных данных

На вход подаётся Telegram-экспорт в формате JSON:

```
chat.json
└── messages: [ ... ]
```

Если структура чата отличается, достаточно адаптировать функцию `extract_text()`.

## Форматы вывода

### JSON

```json
{
  "who": "<ник покупателя или none>",
  "item": "<товар/услуга или none>",
  "price": "<стоимость или none>"
}
```

### CSV

```
message_id,who,item,price,message
```

Результаты сохраняются в файлы:

* `purchases_context.json`
* `purchases_context.csv`

## Как запустить

1. Скачайте модель в локальный каталог.
2. Установите зависимости:

   ```bash
   pip install transformers accelerate bitsandbytes tqdm
   ```
3. Подготовьте файл `chat.json` (экспорт Telegram).
4. Запустите скрипт:

   ```bash
   python pre_relis.py
   ```

После выполнения скрипта выводится информация:

* общее количество найденных покупок
* статистика по товарам

## Настройки

| Параметр              | Где изменяется | Описание                                            |
| --------------------- | -------------- | --------------------------------------------------- |
| Размер окна контекста | `WINDOW = 5`   | Количество сообщений, анализируемых вокруг текущего |
| Путь к модели         | `model_path`   | Можно заменить на любую локальную модель            |
| Формат результатов    | JSON / CSV     | Сохраняются автоматически                           |
